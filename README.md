# The-Last-Guardian-Crown
- O jogo não se aprofundará em Lore, mas segue um pequeno contexto: O jogador surge em uma sala com 5 portas e uma sala do trono com uma coroa acorrentada dentro.
- Objetivos: O objetivo do jogador é explorar cada um dos 5 cenários nas portas e derrotar os Bosses para conseguir a coroa e se tornar o Rei do mundo. 
- Ações: WASD para mover, ESPAÇO para pular, BOTÃO ESQUERDO DO MOUSE para bater, E para interagir, TAB para ataque especial, R para reviver 
- Inimigos: Os inimigos comuns apresentarão comportamento de patrulha, e quando atingidos pelo jogador, buscarão atacá-lo e entrarão em modo de perseguição. 
- Coletáveis: Moeda - É obtida ao derrotar inimigos comuns e Bosses, com mais abundância. /// Vida extra: 8% de chance de ser obtida ao derrotar inimigos comuns e 100% de chance de ser obtido (de 1 a 3) ao derrotar Bosses.
- Condições de Vitória: Derrotar os 5 bosses das fases e coletar 1.000 moedas, desbloqueando a coroa. 
- Condições de Derrota: Perder todos os corações 
- Progressão/Dificuldade: O jogo terá 5 fases/mundos, porém não ficará mais difícil com o tempo, porém mudando o estilo de jogo para cada Boss.  
- Estética: Pixel Art, baseado em Mario/Undertale
